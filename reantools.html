ReanTools

Switch on optional Midnight features with a feature ID.

Download ReanTools

One small file. It works with this and every later Midnight: the list of feature IDs is kept in Midnight itself, so you never need a newer ReanTools for new features.

reantools · 3 KB · for Midnight

Feature IDs

  1. Download ReanTools in Midnight

    Open this page in Firefox in Midnight and select Download ReanTools. It's saved to your Downloads folder.

  2. Put it in place

    Open Terminal (Super + T) and run this. ReanTools only works from the /reantools folder. Select Yes when Admin Approval asks.

    sudo mkdir -p /reantools && sudo install -m 755 ~/Downloads/reantools /reantools/reantools

  3. Switch a feature on

    Run ReanTools with the feature ID, for example Metro Browser:

    /reantools/reantools /enable /id:83729461

    Select Yes when Admin Approval asks. ReanTools answers Command Completed Successfully.

  4. Restart your PC

    The feature is added the next time Midnight starts.

To switch a feature off again, use /disable instead of /enable and restart:

/reantools/reantools /disable /id:83729461

What ReanTools says
Command Completed SuccessfullyDone. Restart to see the change.
The system cannot find the feature ID specifiedThe ID is wrong, the command is typed wrong, or ReanTools isn't in the /reantools folder.
Access is deniedAdmin Approval was cancelled. Run it again and select Yes.

Optional features are extras that aren't part of the standard Midnight. They may change or be removed in later updates.
