About midnightOS

An independent desktop operating system, built in the open on Debian.

What is midnightOS?

midnightOS is a desktop operating system for PCs and laptops. It combines the stability of Debian with its own desktop, apps and settings, designed to be calm, quick and easy to learn.

The Release Preview is the last preview before the final release. Its features are complete; what's left is fixes, branding and new wallpapers.

Built on open source

midnightOS stands on the work of many open-source projects, each under its own licence, including:

  • Debian and the Linux kernel
  • GTK, Openbox, picom and LightDM for the desktop and sign-in
  • GRUB and Plymouth for starting up
  • Firefox ESR for the web
  • Wine for running Windows programs
  • The Inter typeface (SIL Open Font License)

The licences for these components are included in the system under /usr/share/doc.

Privacy

midnightOS doesn't collect usage data. Features that use the internet, such as the weather and the picture-of-the-day background, contact those services only when you use them. Face sign-in data is stored on your PC and never leaves it.

This website doesn't use cookies, analytics or tracking.
