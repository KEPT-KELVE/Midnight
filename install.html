How to install Midnight

Install Midnight from Windows with setup.exe. It takes about 20 minutes.

Setup removes Windows, your apps and every account's AppData folder, and it can't be undone. Your C:\Users folder (Desktop, Documents, Pictures and so on) is kept and shows up in Midnight as Windows files. Back up anything important first.

  1. Check your PC

    You need a PC that runs Windows 10 or 11 and meets the system requirements, with about 25 GB free on C:.

  2. Turn off Secure Boot

    Restart and open your PC's firmware settings (often F2, Del or Esc while it starts). Find Secure Boot, turn it off, then save and exit.

  3. Turn off BitLocker

    If C: is encrypted, open Settings › Privacy & security › Device encryption (or Manage BitLocker in Control Panel) and turn it off. Wait until decryption has finished.

  4. Open the disc image

    Download Midnight with Midnight Setup (select Not now when it offers the USB stick), then double-click the ISO in File Explorer. Windows opens it like a DVD.

  5. Run setup.exe

    Open setup.exe on the disc image and select Yes when Windows asks.

    • Read the notes before you start and what will happen, and tick that you've backed up your files.
    • Setup checks your PC. When it says Your PC is ready, select Install.
    • The screen fills with Installing Midnight and a progress bar. You can still cancel until your PC restarts.

  6. Wait while it installs

    Your PC restarts, installs Midnight, removes Windows and restarts again. Keep it switched on and plugged in.

  7. Set up your PC

    Midnight asks for your time zone, network, name, a PIN and, if you have a camera, face sign-in. It also shows where your Windows files are. Then you're ready.

What setup.exe needs

Start-up modeUEFI, with Secure Boot turned off
Drive encryptionBitLocker and Device encryption turned off on C:
DiskWindows on an NTFS drive on a GPT disk
Free spaceAbout 25 GB free on C:
Your PCMeets the minimum requirements: processor, memory and graphics

You can also start your PC from the disc image on a USB stick and select Install Midnight on the desktop. Setup can put Midnight next to Windows (you choose which one starts each time) or erase the whole disk.

If something goes wrong

Setup says it can't find the Midnight files

Run setup.exe from the opened disc image, not from a copy. If it still says this, download the disc image again.

Setup says your PC isn't ready

Each line says what to change, such as turning off Secure Boot or BitLocker. Fix it, then select Check again. If the processor, memory or graphics line is red, your PC is below Midnight's minimum requirements and Midnight can't be installed on it.

Something went wrong during the install

If it stops before Windows is removed, your PC restarts into Windows with nothing changed. Run setup.exe again and select Clean up to get the space back.

No Wi-Fi

Connect a network cable, or skip the network step during setup and connect later from quick settings.
