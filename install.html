How to install midnightOS

Try midnightOS from a USB stick, then install it on your PC.

Installing erases everything on the disk you choose, including any other operating system. Back up your files first.

  1. Check your PC

    Make sure your PC meets the system requirements, and have a USB stick of 4 GB or more ready. Everything on the stick will be replaced.

  2. Turn off Secure Boot

    Restart and open your PC's firmware settings (often F2, Del or Esc while it starts). Find Secure Boot, turn it off, then save and exit.

  3. Write midnightOS to the USB stick

    Use an image writer such as balenaEtcher, Rufus (in DD mode) or Ventoy to write the midnightOS disc image to the stick.

  4. Start from the USB stick

    Plug in the stick, restart, and open the boot menu (often F12, F11 or Esc). Choose the USB stick. midnightOS starts and signs you in, so you can try it right away.

  5. Install midnightOS

    Double-click Install midnightOS on the desktop.

    • Choose the disk to install on.
    • Tick I understand that everything on this disk will be erased, then select Erase and install.
    • Wait about ten minutes, then select Restart now and remove the USB stick when the screen goes dark.

  6. Set up your PC

    midnightOS starts from the disk and asks for your time zone, network, name, a PIN and, if you have a camera, face sign-in. Then you're ready.

If something goes wrong

The PC doesn't start from the USB stick

Check that Secure Boot is off, try another USB port, and write the stick again.

The screen stays black or shows text

Press Ctrl + Alt + F1 to return to the desktop. If the graphics driver doesn't start, midnightOS switches to a basic display driver by itself.

No Wi-Fi

Connect a network cable, or skip the network step during setup and connect later from quick settings.
