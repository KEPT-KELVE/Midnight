Release notes

What's new and what to know in Midnight 1.0.

VersionMidnight 1.0
Build1.0-20261128-1531
StatusReleased, download now

What's new

  • Midnight 1.0: the first full release. The name is now just Midnight.
  • Updates: Midnight checks for updates when your PC starts and every 12 hours. When one is ready, an update icon appears on the top bar. Download it, then select Restart and update or Update and shut down. Nothing you set up is reset: files, apps, settings, Wi-Fi networks, certificates and Do Not Disturb all stay.
  • Search in Settings: finds individual settings, not just pages. Search for "certificate" and you land on Certificates.
  • Shut down with Alt + F4: press Alt + F4 on the desktop, then Enter to shut down, or pick restart, sleep, sign out, switch user or lock.
  • New security screen: Ctrl + Alt + Delete has been redesigned.
  • New Project menu: Super + P shows your display choices as pictures; press it again to move through them.
  • Your PC's logo at start-up: PCs from brands such as ASUS, Dell, HP and Lenovo show their own logo while Midnight starts. Other PCs show the Midnight logo.
  • New install and repair screens: installing shows a spinner with the percentage, and automatic repair shows the start-up screen with what it's doing.
  • Minimum requirements: Setup checks your PC before it installs and lists anything that's missing.
  • Daisies: the new default desktop background.

Changed

  • Tablet mode has been removed for now. It will come back, better, in an update.
  • The Upgrade option has been removed from the disc image. New versions come through Settings › Update.
  • The preview watermark is gone.

Known issues

  • Secure Boot must be turned off to start Midnight.
  • setup.exe, run from Windows, replaces Windows (you can go back for 45 days). To keep both, install from a USB stick instead.
  • Installing next to Windows from a USB stick needs BitLocker off, a GPT disk and a UEFI start, and Windows must have been shut down fully (not Fast Startup).
  • Some system actions that have no approval prompt yet, such as formatting a disk in the Disks app, are refused instead of asking.
  • English is the only language.
