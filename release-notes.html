Release notes

What's new and what to know in midnightOS 0.9 Release Preview.

VersionmidnightOS 0.9 Release Preview
Build0.9_RP-20261127-2312
StatusRelease Preview, download now

What's new

  • Release Preview: midnightOS is now feature complete. From here on, updates bring fixes, branding and new wallpapers.
  • New icons: every app, folder, device and file icon has been redrawn, with violet folders.
  • Full-screen Start: a new vines and moons background, drawn in whatever Start colour you choose.
  • Tablet mode: use full-screen Start as your home screen, without the taskbar or menu bar.
  • Wet Glass: set how transparent the taskbar is in Settings › Personalization › Taskbar.
  • Red Roses: the new default desktop background.
  • Keep Windows: install from a USB stick next to Windows and choose which one starts.
  • Optional features: switch on extra parts of midnightOS, such as Metro Browser, with ReanTools and a feature ID. midnightOS keeps its own list of IDs, so the ReanTools you download today keeps working with every later update.

Fixed

  • Wallpapers that were removed no longer stay behind after an update.
  • The release name now reads Release Preview everywhere, including the watermark and first start.
  • Face sign-in can be set up from Settings without an extra password prompt.
  • The sign-in screen clock follows the time zone you choose.

Known issues

  • Secure Boot must be turned off to start midnightOS.
  • setup.exe, run from Windows, replaces Windows (you can go back for 45 days). To keep both, install from a USB stick instead.
  • Installing next to Windows from a USB stick needs BitLocker off, a GPT disk and a UEFI start, and Windows must have been shut down fully (not Fast Startup).
  • Some system actions that have no approval prompt yet, such as formatting a disk in the Disks app, are refused instead of asking.
  • English is the only language.
