Release notes

What's new and what to know in midnightOS 0.9 Developer Preview.

VersionmidnightOS 0.9 Developer Preview
Build951121202612_Dev-20261117-2141
StatusComing soon

What's new

  • Install midnightOS: install from the USB stick onto a disk, with UEFI and legacy BIOS support.
  • First start: a short setup for time zone, network, your name, a PIN, face sign-in and theme.
  • Sign-in: starting from a USB stick signs in automatically; installed PCs use your PIN or face.
  • New look: a new logo, new app icons, a new boot screen and a white loading spinner.
  • New sounds: an original set of system sounds and new music for the Metro Browser welcome.
  • Metro Browser: new icons throughout, a new logo, and it now installs as a regular package.
  • Admin Approval: a clearer prompt that shows which app is asking and what it will run.

Fixed

  • Face sign-in can now be set up from Settings without an extra password prompt.
  • The sign-in screen clock now follows the time zone you choose.
  • Start and Settings now show the name you enter during first start.
  • Window previews on the taskbar show the right app names.

Known issues

  • Secure Boot must be turned off to start midnightOS.
  • Installing uses the whole disk. Installing next to another operating system isn't supported yet.
  • Some system actions that have no approval prompt yet, such as formatting a disk in the Disks app, are refused instead of asking.
  • English is the only language.
