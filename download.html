midnightOS Setup for Windows

The easiest way. Setup downloads midnightOS in 3 parts at the same time (keep using your PC, it works in the background), joins them into the disc image, checks it, then writes it to a USB stick for you. Start your PC from the stick and select Install midnightOS: keep Windows next to it, or replace it.

How to install Release notes System requirements
