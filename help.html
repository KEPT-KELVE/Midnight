Help and support

Answers to common questions, troubleshooting and keyboard shortcuts.

Getting started

Is Midnight free?

Yes. It's free to download and use, and it's built on free and open-source software.

How do I install it?

In Windows, open the disc image and run setup.exe. See How to install.

Can I start it from a USB stick?

Yes. Start your PC from the disc image and select Install Midnight on the desktop. You can keep Windows next to it (dual boot) or erase the whole disk.

Can I keep Windows?

Yes, if you install from a USB stick and choose to keep Windows. setup.exe, run from inside Windows, replaces Windows and keeps your C:\Users folder as Windows files.

Why do I need to turn off Secure Boot?

Midnight's boot loader isn't signed yet, so PCs with Secure Boot on won't start it.

Using Midnight

How do I update Midnight?

Midnight checks by itself. When an update is ready, select the update icon on the top bar (or open Settings › Update), select Download, then Restart and update. Nothing you set up is reset.

How do I change my PIN?

Open Settings › Accounts.

How do I set up face sign-in?

Open Settings › Accounts › Face recognition and follow the steps. You need a camera.

Can I run Windows programs?

Many Windows programs (.exe files) run through a compatibility layer. Double-click the file to start it. Some programs and games won't work.

How do I take a screenshot?

Press Print Screen. The picture is saved in Pictures › Screenshots.

How do I remove an app?

Open Settings › Apps › Add or remove apps.

Troubleshooting

The screen is black or shows text

Press Ctrl + Alt + F1 to return to the desktop. If the graphics driver doesn't start, Midnight switches to a basic display driver by itself.

Wi-Fi doesn't show any networks

Check that Wi-Fi is on in quick settings (Super + A). If your adapter isn't supported, use a network cable.

An app asks for administrator approval

Admin Approval shows which app is asking and what it will run. Allow it only if you started the app and trust it.
